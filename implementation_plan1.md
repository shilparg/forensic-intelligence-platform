## Proposed Changes

---
### Phase 1: Ingestion Pipeline (Bronze & Silver)
**Goal:** Extract Yahoo Finance data and load it as a structured table into your BigQuery Silver dataset.

#### [NEW] `meltano_elt_engine/yahoo_to_bq.py` (or update existing)
- Set up the script to read Meltano's Yahoo Finance JSON output.
- Map and flatten nested financial metrics (`shortRatio`, `debtToEquity`, `returnOnEquity`, etc.).
- Load the structured records into BigQuery exactly at `raw_sec_landing.raw_financials`.

---
### Phase 2: dbt Transformation (Gold)
**Goal:** Use the cloud warehouse to securely clean and join Engine A (text data) with Engine B (financials).

#### [NEW] `core_nlp_engine/transform_dbt/models/staging/stg_financials.sql`
- Read directly from `{{ source('sec_sources', 'raw_financials') }}`.
- Cast market metrics (ratios, margins) to standardized `FLOAT64` data types, and handle any `NULL` values.

#### [MODIFY] `core_nlp_engine/transform_dbt/models/marts/intermediate/int_forensic_metrics.sql`
- Perform a massive `LEFT JOIN` on the `ticker` (and optionally `fiscal_year`) combining `stg_sec_filings` (Engine A) and `stg_financials` (Engine B).
- Output the clean, unified table to the `forensic_data` BigQuery dataset.

---
### Phase 3: Machine Learning Refactor (The Presentation Layer)
**Goal:** Point the Isolation Forest model permanently at the newly unified Gold dataset and bypass all local rate limits.

#### [MODIFY] `core_nlp_engine/ml_engine/fraud_model.py`
- Modify the script to execute `SELECT * FROM forensic_data.int_forensic_metrics`.
- Completely delete the `yfinance` API `for` loops and `time.sleep()` logic.
- The model instantly trains on the joined DataFrame in seconds, spitting out `ai_scored_forensic_dataset.csv` strictly for Streamlit to consume seamlessly.
